## 📌 1. Math Quiz Web Application 🎯  

An interactive **Math Quiz** game that tests users with randomly generated math problems. The quiz supports different difficulty levels, has a timer-based system, and keeps track of points.

### 🛠 Features
- **Three Difficulty Levels**: Easy, Medium, and Hard.
- **Dynamic Question Generation**: Addition, Subtraction, Multiplication, and Division.
- **Multiple Choice Questions**: Four answer options for each question.
- **Timer-Based Gameplay**: Answer before time runs out.
- **Points System**: Earn or lose points based on answers.

### 🚀 Technologies Used
- **HTML**: Structure of the webpage.
- **CSS**: Styling and layout.
- **JavaScript**: Game logic, random question generation, and user interactions.

# Math Quiz Web Application

This is an interactive **Math Quiz** web application that challenges users with randomly generated math problems at different difficulty levels. The game features a timer-based system and a points tracker.

## 🛠 Features
- **Three Difficulty Levels**: Easy, Medium, and Hard.
- **Dynamic Question Generation**: Random arithmetic questions (Addition, Subtraction, Multiplication, Division).
- **Multiple Choice Questions**: Four answer options for each question.
- **Timer-Based Gameplay**: Answer within the given time.
- **Points System**: Earn or lose points based on correct and incorrect answers.

## 🚀 Technologies Used
- **HTML**: Structure of the webpage.
- **CSS**: Styling and layout.
- **JavaScript**: Game logic, random question generation, and interactive features.
